Phishing Awareness Training

CodeAlpha Cybersecurity Internship – Task 2

1. Introduction

Phishing is a cyberattack in which attackers trick users into sharing sensitive information through fake emails, messages, and websites.

2. Project Objectives

- Understand different phishing attacks.
- Identify suspicious emails and messages.
- Learn how phishing attacks work.
- Understand phishing prevention techniques.
- Promote cybersecurity awareness.

3. Types of Phishing

- Email Phishing
- Spear Phishing
- Whaling
- Smishing
- Vishing

4. Warning Signs

- Suspicious email addresses.
- Urgent or threatening messages.
- Unknown links.
- Spelling and grammar mistakes.
- Requests for passwords or OTPs.

5. Prevention Methods

- Use strong passwords.
- Enable two-factor authentication.
- Avoid suspicious links.
- Update security software.
- Verify messages before responding.

6. Tools Used

- Microsoft PowerPoint
- GitHub

7. Deliverable

A 10-slide presentation explaining phishing attacks, warning signs, prevention, and safety measures.

8. Conclusion

Cybersecurity awareness helps users protect their personal information and avoid phishing attacks.
